## Sobre o projeto
O jogador controla um personagem onde ele terá que escolher uma porta é ver se a certa para conseguir passar. 

## O que o projeto faz
O jogador controla um personagem usando as teclas WSAD enquanto mexe o mouse para controlar a câmera,
o jogador terá que escolher uma porta usando a tecla E para ver se ela abre ou não,
se não abrir terá que tentar outra porta se abrir o jogador conseguiu. 

**Scripts:** 
GerenciadorDePortas, interacao, jogador, porta.

**Objetos principais:** 
Jogador, Chão, Porta (1), Porta (2), Porta (3), Gerenciador, Beta_Joints, Beta_Surface.  

**Recursos usados:**
MeshRenderer, TextMashPRO, BoxCollider, CharacterController. 

## Controles
W- vai pra frente
S - Vai para trás 
A- Vai para a direita 
D- Vai para a esquerda
MOUSE- para mexer a câmera
E- para interagir com a porta
